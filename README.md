# 🌙 رویاچین — Workers App

مدیریت آرزوها و هزینه‌ها به فارسی — یک فایل Worker که کل اپ + سرویس‌آفلاین + آیکون + همگام‌سازی ابری را سرو می‌کند.

## 🚀 دیپلوی روی Cloudflare

### ۱) ساخت KV Namespace

```
wrangler kv namespace create KWP_KV
```

خروجی یک `id` می‌دهد؛ آن را در فایل `wrangler.toml` بگذار:

```toml
name = "kifpool"
main = "workers.js"
compatibility_date = "2024-09-01"

[[kv_namespaces]]
binding = "KWP_KV"
id = "XXXXXXXXXXXXXXXXXXXXXXXXXX"   # ← id از دستور بالا
```

### ۲) دیپلوی

```
wrangler deploy
```

همین! اپ روی دامنه‌ی HTTPS شما بالا می‌آید و **بدون KV هم کار می‌کند** (فقط همگام‌سازی غیرفعال می‌ماند).

## ☁️ همگام‌سازی بین دستگاه‌ها

در تب «تنظیمات → همگام‌سازی ابری»:

1. یک **کد اتاق** بسازید یا وارد کنید (مثلاً `kif-7x2p`)
2. همان کد را روی دستگاه دوم هم وارد کنید
3. هر تغییری (ثبت/ویرایش/حذف/واریز) بعد از چند ثانیه به‌صورت خودکار در همه‌ی دستگاه‌ها همگام می‌شود

- ادغام بر اساس زمان آخرین تغییر است؛ حذف‌ها هم (tombstone) منتقل می‌شوند.
- دیتا روی **Cloudflare KV** ذخیره می‌شود — هر کسی که کد اتاق را بداند به آن دسترسی دارد.
- برای پاک کردن دیتای ابر: دکمه «پاک کردن دیتای ابر» (با تأیید ۳ ثانیه‌ای).

## ⚙️ ساخت مجدد خروجی‌ها

```
python3 build.py
```

خروجی‌ها:
- `workers.js` — فایل Worker (خروجی اصلی)
- `preview.html` — پیش‌نمایش استندالون دسکتاپ

سورس اصلی: `src/app.html` (فونت وزیرمتن و آیکون هم در build به‌صورت inline جاسازی می‌شوند).

## 🧪 تست

```
node /tmp/test_sync.mjs        # تست API worker
node /tmp/synctest/integration.mjs  # تست انتگراسیون دو دستگاه
```

- Clipboard/WebOTP فقط روی HTTPS/لوکال‌هاست فعال‌اند.
- شیک و لرزش فقط روی گوشی واقعی.
